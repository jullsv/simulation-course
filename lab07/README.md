## Реализация
Программная реализация модели базируется на использовании непрерывной однородной цепи Маркова. Основной логикой генерации траектории процесса управляет класс MarkovWeatherGenerator, а статистической обработкой результатов — класс MarkovWeatherCalculate.
Диагональные элементы матрицы вычисляются как сумма интенсивностей переходов из данного состояния:

$$
q_{ii} = -\sum_{j \neq i} q_{ij}
$$

Время пребывания в состоянии распределено по экспоненциальному закону:

$$
\tau = -\frac{\ln(\alpha)}{\lambda}
$$

где: 
- $$\(\alpha \in (0,1)\)$$ - случайное число;
- $\lambda = -q_{ii}$ — интенсивность выхода из состояния $i$;

Следующее состояние выбирается как дискретная случаная величина с вероятностями:

$$ p_{ij} = \frac{q_{ij}}{-q_{ii}} $$

Методом инверсии (накопления вероятностей) выбирается следующее состояние.
```python
def generate_next(self, state):
    i = state - 1
    rate = -self.Q[i][i]

    # Генерация времени пребывания в состоянии (экспоненциальное распределение)
    tau = -math.log(random.random()) / rate

    probs = []
    next_states = []

    # Расчет вероятностей перехода в другие состояния
    for j in range(3):
        if j != i:
            probs.append(self.Q[i][j] / rate)
            next_states.append(j + 1)

    # Выбор следующего состояния методом накопления вероятностей
    A = random.random()
    for k in range(len(probs)):
        A -= probs[k]
        if A <= 0:
            return next_states[k], tau

    return next_states[-1], tau
```

Моделирование реализуется в методе experiment(T), который симулирует процесс на временном интервале [0,T]. Алгоритм представляет собой цикл, в котором последовательно генерируются переходы до тех пор, пока накопленное время не превысит заданный горизонт моделирования T.
Особенностью реализации является корректная обработка последнего интервала: если сгенерированное время перехода τ выходит за пределы T, то в счетчик времени пребывания добавляется только остаток времени (T−t), и моделирование завершается.
```python
def experiment(self, T):
    t = 0
    state = self.start_state

    times = [0]
    states = [state]
    durations = [0.0, 0.0, 0.0]

    while t < T:
        new_state, tau = self.generate_next(state)

        # Проверка выхода за границы времени моделирования
        if t + tau > T:
            durations[state - 1] += T - t
            break

        durations[state - 1] += tau
        t += tau
        state = new_state

        times.append(t)
        states.append(state)

    return times, states, durations
```
### Статистическая обработка результатов
После завершения эксперимента производится сравнение эмпирических данных с теоретическими предсказаниями.
```python
def empirical_distribution(self, durations):
    total = sum(durations)
    if total == 0:
        return [0.0, 0.0, 0.0]
    return [d / total for d in durations]
```
### Теоретическое стационарное распределение
```python
def stationary_distribution(self):
    # Транспонируем матрицу Q для решения системы pi * Q = 0 => Q^T * pi^T = 0
    A = self.Q.T.copy()
    b = np.zeros(3)
    
    # Замена последнего уравнения на условие нормировки sum(pi) = 1
    A[2] = np.ones(3)
    b[2] = 1
    
    pi = np.linalg.solve(A, b)
    return pi.tolist()
```
