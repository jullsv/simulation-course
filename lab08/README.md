### Пуассоновский поток. События на сервере
Моделирование потока заявок на сервер.

**Задание:**
- событие — поступление заявки;
- определить число заявок за интервал времени T;
- построить распределение числа заявок;
- вычислить среднее и дисперсию;
- сделать вывод.

# Лабораторная работа №8
## Теория
Работа базируется на модели простейшего (стационарного пуассоновского) потока.

Свойства простейшего потока:
- Независимость: События не зависят друг от друга.  
- Ординарность: В один момент времени может прийти только один запрос. 
- Стационарность: Вероятность появления определенного числа событий на интервале зависит только от его длины $T$, а не от того, когда этот интервал начался.

Для моделирования используется метод обратной функции (генератор): $$\tau_i = -\frac{\ln(\alpha_i)}{\lambda}$$

где:
- $\lambda$ — интенсивность потока (среднее число событий в единицу времени);
- $\alpha_i$ — случайное число, равномерно распределенное на интервале $(0, 1]$.

Моменты наступления событий $t_i$ вычисляются рекуррентно:
  $$t_i = t_{i-1} + \tau_i, \quad t_0 = 0$$
  
Процесс продолжается до выполнения условия $t_i < T_{sim}$, где $T_{sim}$ — заданное общее время моделирования.
## Статистическая обработка
Для анализа полученного потока применяется метод разбиения на интервалы фиксированной длины $T$. 

Весь временной отрезок $[0, T_{sim}]$ делится на $N$ участков:

  $$N = \lfloor T_{sim} / T \rfloor$$Для каждого $j$-го интервала подсчитывается количество попавших в него событий $k_j$. 
Согласно теории, дискретная случайная величина $k$ должна подчиняться закону Пуассона:
  $$P(k) = \frac{(\lambda T)^k \cdot e^{-\lambda T}}{k!}$$
## Cтатистические показатели

Программа вычисляет основные статистические показатели выборки:  
- Выборочное среднее (E): $\bar{k} = \frac{1}{N} \sum_{j=1}^{N} k_j$
- Выборочная дисперсия (D): $S^2 = \frac{1}{N-1} \sum_{j=1}^{N} (k_j - \bar{k})^2$
- Теоретические значения: для пуассоновского потока справедливо равенство $M[k] = D[k] = \lambda T$.

Соответствие модели проверяется через индекс дисперсии (отношение $D/E$). 

Если значение близко к $1$, это подтверждает свойства стационарности, ординарности и отсутствия последействия моделируемого потока запросов.
