### Система массового обслуживания M/M/* с усложнениями

Реализовать систему M/M/* с **двумя дополнительными правилами** (ООП).

**Возможные усложнения:**
- ограничение числа приборов (вероятность отказа);
- очередь;
- нетерпеливость заявок;
- требования к ресурсам (детерминированные или случайные).
  
### Реализация
M/M/n/m (система с n серверами и ограниченной очередью на m мест).

- Ограничение числа приборов (n>1).
- Очередь (ограниченная длиной m).

Если заявка приходит, когда все n серверов заняты и очередь заполнена (m мест), она получает отказ.

Логика работы:

1. Заявка поступает в систему.
2. Если есть свободный сервер (<n занятых), заявка немедленно начинает обслуживаться.
3. Если все серверы заняты, но очередь не полна (<m заявок в очереди), заявка встает в очередь.
4. Если все серверы заняты и очередь заполнена, заявка получает отказ и покидает систему навсегда.
5. При освобождении сервера, если очередь не пуста, первая заявка из очереди переходит на обслуживание.

Потребуется ввести:

- lambda — интенсивность входящего потока.
- mu — интенсивность обслуживания одним сервером.
- n — количество серверов.
- m — размер очереди.
- T — время моделирования.
