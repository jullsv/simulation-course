### Теория 1


**Теоретические характеристики:**

Математическое ожидание: $E x = \sum_{i=1}^{m} p_i x_i$

Дисперсия: $\text{Var } x = D x = \sum_{i=1}^{m} p_i (x_i - E x)^2 = \sum_{i=1}^{m} p_i x_i^2 - (E x)^2$

**Эмпирические характеристики:**

Относительная частота (эмпирическая вероятность):
$$\hat{p}_i = \frac{n_i}{N}$$
где $n_i$ — количество выпадений значения $x_i$.

Выборочное среднее:
$$\hat{E}[x] = \sum_{i=1}^{m} \hat{p}_i x_i$$

Выборочная дисперсия:
$$\hat{D}[x] = \sum_{i=1}^{m} \hat{p}_i x_i^2 - (\hat{E}[x])^2$$

Относительная погрешность:
$$\delta = \frac{|X_{теор} - X_{эмп}|}{|X_{теор}|}$$

**Критерий ($\chi^2$):**

Статистика хи-квадрат:
$$\chi^2 = \sum_{i=1}^{m} \frac{(n_i - N p_i)^2}{N p_i}$$

Проверка гипотезы $H_0$ (уровень значимости $\alpha = 0.05$):
*   Если $\chi^2 > \chi^2_{crit}$, то гипотеза **отвергается**.
*   Если $\chi^2 \le \chi^2_{crit}$, то гипотеза **принимается**.
*Для 5 исходов df=4, критическое значение χ²_{crit} ≈ 9.488*

### Теория 2

**Генерация (Метод Бокса-Мюллера):**

Из двух независимых равномерных величин $U_1, U_2 \sim Uniform(0, 1)$ получаем стандартные нормальные $Z_0, Z_1$:

$$ Z_0 = \sqrt{-2 \ln U_1} \cdot \cos(2\pi U_2) $$
$$ Z_1 = \sqrt{-2 \ln U_1} \cdot \sin(2\pi U_2) $$

Преобразование к заданным параметрам $\mu$ (среднее) и $\sigma$ (стандартное отклонение):
$$X = \mu + \sigma Z$$

**Функция распределения для расчета ожидаемых частот:**

$$ F(x) = \frac{1}{2} \left[ 1 + \text{erf}\left( \frac{x - \mu}{\sigma \sqrt{2}} \right) \right] $$

Вероятность попадания в интервал $[x_{left}, x_{right}]$:
$$P(x_{left} < X < x_{right}) = F(x_{right}) - F(x_{left})$$
## Дискретная случайная величина

Класс DiscreteValues реализует имитационное моделирование дискретной случайной величины (ДСВ) по заданному ряду распределения.
Сразу вычисляются математическое ожидание и дисперсия.

Метод нормализации normalize делит каждую вероятность на общую сумму. Это обеспечивает выполнение условия (сумма вероятностей равна 1), необходимого для корректной работы генератора.
Метод experiment cоздает список counts для хранения частот.
Словарь val_to_idx нужен для быстрого поиска индекса значения.
Цикл выполняется N раз. Каждый раз генерируется новое значение x, и счетчик для этого значения увеличивается на 1.
Возвращает массив частот.

Алгоритм:

- Мы получаем случайное число α из равномерного распределения [0,1).
- Начинаем проверку с первого элемента массива.
- Запускаем цикл, который будет перебирать вероятности по очереди, пока не найдет нужную.
- Вычитаем из нашего случайного числа вероятность текущего элемента.
- Если после вычитания число стало меньше или равно нулю, значит, наша случайная точка A попала в текущий интервал.
- Возвращаем значение x, которое соответствует этому интервалу. Моделирование одного значения завершено.
- Если условие A <= 0 не выполнилось (число все еще положительное), переходим к следующему элементу массива (увеличиваем индекс) и повторяем вычитание.

## Нормальная случайная величина
Код реализует генерацию и статистическую проверку нормального распределения.

Задаёт параметры нормального распределения:

- mu — среднее (математическое ожидание)
- sigma — стандартное отклонение (корень из дисперсии)
- Использует базовый генератор равномерных чисел (BaseGenerator)

Генерирует N случайных чисел, распределённых по нормальному закону N(μ, σ²), используя метод Бокса-Мюллера:

- Берёт два равномерных числа U₁, U₂ ∈ (0,1]
- Преобразует их в две независимые стандартные нормальные величины Z₀, Z₁
- Масштабирует до нужных μ и σ: X = μ + σ·Z
- Возвращает ровно N значений (если нужно нечётное количество — обрезает лишнее)
- если U₁ = 0, заменяется на 1e-10


Вычисляет функцию распределения (CDF) нормального закона в точке x через функцию ошибок erf. Нужна для расчёта теоретических вероятностей попадания в интервалы.

Применяет критерий хи-квадрат к непрерывной выборке (нормальное распределение).

# Вывод

В ходе выполнения лабораторной работы был реализован алгоритм генерации дискретной случайной величины с заданным рядом распределения. С увеличением объема выборки эмпирическое распределение стремится к теоретическому, что подтверждает состоятельность метода моделирования.

Также был реализован генератор нормальной СВ методом Бокса-Мюллера с параметрами μ, σ². При малых N (10, 100): Наблюдаются большие отклонения выборочных характеристик от теоретических (погрешность дисперсии до 697.9% при N=10). Гистограмма не соответствует теоретической кривой нормального распределения. Критерий χ² значительно превышает критическое значение 16.92, гипотеза H₀ отвергается. Можно сказать, что иетод Бокса-Мюллера обеспечивает качественную генерацию нормально распределенных величин, однако для получения статистически значимых результатов требуется достаточно большой объем выборки (N ≥ 10000).

Критерий хи-квадрат показал свою эффективность для проверки гипотез о распределении: при малых N гипотеза отвергается, при больших N - принимается (эмпирическое распределение сходится к теоретическому).
